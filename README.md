# Ruta

Ruta is a phone-browser ride booking app. A rider asks for a ride. A driver takes it. The rider pays the driver in cash or by a direct wallet transfer.

Drivers are not charged while the service is being tried out.

## Run it

```bash
npm install
npm run dev
```

Open the site and create the admin with a name, a US, Canada, or Peru mobile number, and a 6-digit PIN. The dashboard is at `/dashboard`.
